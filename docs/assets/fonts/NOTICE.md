# Fontes de terceiros

Os arquivos `Lexend-*.ttf` desta pasta são da família tipográfica
**Lexend**, distribuída sob a **SIL Open Font License, Version 1.1**.

- Projeto: <https://www.lexend.com/>
- Repositório: <https://github.com/googlefonts/lexend>
- Texto da licença: <https://openfontlicense.org/>

A OFL permite uso, redistribuição e modificação, inclusive comercial, desde
que as fontes não sejam vendidas isoladamente e que este aviso acompanhe os
arquivos.

> **Pendência:** o ideal é incluir o arquivo `OFL.txt` original junto às fontes,
> baixado de <https://github.com/googlefonts/lexend/blob/main/OFL.txt>.
> Este aviso identifica a licença, mas não substitui o texto integral.
